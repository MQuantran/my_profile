Line Following Mouse

Autonomous line-tracking robot using IR sensors and PID control

Project Overview

Designed and built a compact autonomous robot ("mouse") that follows a dark line on a light surface using an array of infrared reflectance sensors. A tuned PID controller converts sensor readings into real-time steering and throttle commands, enabling the robot to stay on track through straight sections, curves, and intersections at speed.

Sensing & Perception

The robot uses an array of infrared (IR) reflectance sensors mounted on the underside of the chassis. Each sensor emits IR light and measures the reflected intensity — dark surfaces (the line) reflect less light than the surrounding white surface, providing a contrast signal.

  • Multi-Sensor Array: Multiple IR sensors arranged in a line provide a weighted position estimate of the track relative to the robot's centre.
  • Signal Conditioning: Raw analog readings are filtered and normalised to compensate for ambient light variation and surface reflectivity differences.
  • Position Estimation: A weighted-average algorithm computes the track offset as a continuous value, enabling smooth proportional control rather than discrete left/right decisions.

PID Control Strategy

The core control loop uses a Proportional-Integral-Derivative (PID) controller to minimise the lateral error between the robot and the line centre.

  • Proportional (P): Generates steering correction proportional to the current offset — the further off-centre, the harder it steers back.
  • Integral (I): Accumulates past error to correct persistent drift, ensuring the robot converges to the line even with asymmetric friction or motor differences.
  • Derivative (D): Responds to the rate of change of error, damping oscillation and providing predictive correction before the robot overshoots.
  • Tuning: PID gains were iteratively tuned through systematic testing on tracks of increasing complexity, balancing responsiveness against stability at higher speeds.

Speed Optimisation

Beyond basic line following, the control system was optimised for speed:

  • Adaptive Speed Control: The robot reduces speed through tight curves (detected by large lateral error) and accelerates on straight sections, maximising average lap time.
  • Derivative-Based Braking: A high rate of change in error triggers preemptive deceleration before sharp turns, preventing the robot from leaving the track.
  • Motor Calibration: Differential motor responses were characterised and compensated to ensure symmetric turning behaviour at all speeds.

What I Learned

  • Control Theory in Practice: Translating PID equations from theory to a physical system revealed the importance of sampling rate, sensor noise, and actuator latency.
  • Tuning Trade-offs: Aggressive P gains improve tracking on curves but cause oscillation on straights — finding the balance required systematic experimentation.
  • Hardware Constraints: Battery voltage drop, motor dead-zones, and sensor mounting tolerances all required software compensation strategies.
  • Iterative Design: Each test run informed mechanical and software refinements — sensor spacing, wheel alignment, and code structure evolved together.
